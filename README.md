This project focuses on classifying EEG brainwave signals into seizure and non-seizure categories using a Multi-Layer Multi-Spiking Neural Network (MLMSNN). It applies EEG preprocessing, spike-train encoding, and Mini-Batch SGD optimization to improve real-time neurological signal analysis and seizure detection performance.

TECH STACK:

• Packages: PyTorch, NumPy, SciPy, MNE, Matplotlib.

• EEG preprocessing and spike-train encoding

• Optimization using Mini-Batch SGD

• Model: Multi-Layer Multi-Spiking Neural Network (MLMSNN)

Dataset
Source: [Kaggle – Epileptic Seizure Recognition Dataset](https://www.kaggle.com/datasets/harunshimanto/epileptic-seizure-recognition?utm_source=chatgpt.com)

The dataset contains EEG (Electroencephalogram) brainwave recordings used for epileptic seizure recognition and neurological signal analysis.

It consists of numerical EEG signal features collected from multiple brain activity recordings, where the target labels represent seizure and non-seizure conditions for classification tasks.
